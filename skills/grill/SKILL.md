# Grill

1. 先阅读相关代码和文档，自行查清可查证的信息，梳理关键决策及依赖。
2. 每轮提出 3–5 个相互独立的问题；剩余问题不足时按实际数量提问。先解决前置决策，再问依赖它的问题。
3. 每个问题附上明确的推荐答案和简短理由。
4. 每轮问完等待用户回答。保留已确认的决定，只追问遗漏或仍有歧义的部分。
5. 持续推进，直到目标、关键取舍和验收标准清楚；总结决定、理由、风险、未决事项及下一步。

用户另行要求实施前，不开始实现。
